## What it is

- Spend Wise is a Flutter-based budgeting and shopping expense management application that helps users plan their shopping budget, record shopping trips, and track their expenses. It is designed to help students, young professionals, and budget-conscious individuals manage their spending and avoid going over budget when shopping.
## How to run it

Prerequisites
-Flutter SDK
-Dart SDK (included with Flutter)
-Visual Studio Code or another Flutter-compatible IDE
-Android emulator, physical device, or Google Chrome for web testing

Steps to run the application

1. Clone the project repository:

git clone https://github.com/hannanicoleangeles5/Shop_Tracker.git

2. Open the project folder:

cd Shop_Tracker

3. Open the project in Visual Studio Code or your preferred IDE.
4. Check whether Flutter is installed and configured correctly:

flutter doctor

5. Install the project's dependencies:

flutter pub get

6. Run the application on an available device or emulator:

flutter run

To run the application in Google Chrome, use:

flutter run -d chrome

7. Explore the application's screens and test its available budgeting and shopping expense management features.

Note: Make sure an appropriate emulator, physical device, or supported browser is available before running the application. No external API keys are currently required.
